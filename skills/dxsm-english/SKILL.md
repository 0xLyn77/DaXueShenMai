# 考研英语作文与翻译批改

## 选择批改规则

确定卷别和题型，完整读取对应参考文件，按其中的评分与输出要求批改。卷别或题型不明时先询问。

| 用户任务 | 必读规则 |
|---|---|
| 英语一大作文（20 分） | [英语一大作文](references/english-1-essay.md) |
| 英语一小作文（10 分） | [英语一小作文](references/english-1-letter.md) |
| 英语二大作文（15 分） | [英语二大作文](references/english-2-essay.md) |
| 英语二小作文（10 分） | [英语二小作文](references/english-2-letter.md) |
| 英语一翻译（5 句，每句 2 分） | [英语一翻译](references/english-1-translation.md) |
| 英语二翻译（15 分） | [英语二翻译](references/english-2-translation.md) |

## 执行要点

- 严格客观，不刻意抬分或压分；分数仅供练习参考。模拟采分点、作文评分侧重和练习扣分约定不得冒充官方标准。
- 手写图片先准确转录，保留原有错误；无法辨认处请用户确认，不猜测或把识别错误当作作答错误。
- 作文先核对题目与任务，执行对应的切题性强化原则，再综合定档。缺题目或关键图片时可先改语言，暂不给确定总分。
- 翻译依据英文原文及上下文判断，参考译文仅供对照；缺少必要信息时按对应规则说明不确定性或提醒补充，不编造。
- 区分必须修改的错误与可选优化，保留原意和正确表达；逐句批改、修改全文、复盘积累及顺序以对应参考文件为准。
- 修改句与完整修改版统一按下方「修改展示与配色规范」呈现，禁止仅用 Markdown 加粗（`**...**`）标注主要修改；环境具备 `generative_ui` 能力时优先结合使用。

## 修改展示与配色规范

全部题型的修改句、修改译文与完整修改版均按颜色区分修改类型，完整细则与样式约定见 [修改展示与配色规范](references/diff-display.md)：

- **统一三色语义**：**绿色**＝替换或修改后的正确表达；**蓝色**＝补全的漏译、缺失冠词/成分或新增必要衔接；**红色（带删除线）**＝原文中的错误表达（用于删改对照）。
- **优先内联彩色交互卡片**：当运行环境支持内联 HTML 组件（如具备 `generative_ui` skill 或 `<agent-embed>` 渲染能力）时，优先结合使用生成紧凑交互卡片（目标高度 ≤ 450px，避免外层卡片嵌套与内部滚动条），内置「彩色修改版 / 红绿删改对照」视图切换、「全文 / 第 1 句 … 第 N 句」范围筛选（单句上方同步显示对应题干原句）、点击高亮片段在底部固定批注栏查看原因（区分【必须修改】/【可选优化】）及「复制修改全文」按钮；配色使用宿主语义 CSS 变量（`--foreground`、`--muted-foreground`、`--card`、`--card-border`、`--success`、`--primary`、`--error`）配合 `color-mix()`，禁止硬编码深浅背景色。
- **纯文本 / 无 HTML 环境降级**：当宿主不支持内联 HTML 渲染或用户要求直接写入本地 `.md` 文件时，禁止退回单纯的 `**加粗**`——支持行内颜色的渲染器可使用彩色标签或 KaTeX 颜色标记；严格纯 Markdown 环境使用 `diff` 代码块（`-` 原句 / `+` 修改句）逐句对照，并以行内标注列出具体改动点，另附干净可复制的修改后全文。
