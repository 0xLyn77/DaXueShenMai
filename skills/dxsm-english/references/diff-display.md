# 修改展示与配色规范

本规范适用于 `dxsm-english` 全部六类题型（英语一/二大小作文与英译汉）的「逐句批改（修改句/修改译文）」与「修改后全文 / 完整修改版 / 修改对照」。执行时保持各题型参考文件规定的评分标准、档位说明、切题性原则与输出大纲顺序不变，仅升级修改呈现方式。

## 1. 统一颜色语义规范

不再使用单纯的 Markdown 加粗（`**...**`）区分主要修改，统一采用三种颜色区分修改类型：

| 颜色 | 语义 | 典型适用场景 |
|---|---|---|
| **绿色** | 替换或修改后的正确表达 | 拼写/语法/搭配/词义纠正、误译更正、语态或时态修正、句式优化替换 |
| **蓝色** | 补全的漏译、缺失冠词/成分或新增必要衔接 | 补齐遗漏的英文信息点、缺失冠词/介词/主谓成分、增补段落或句间逻辑衔接词 |
| **红色（带删除线）** | 原文中的错误表达 | 用于删改对照，直观标记被替换或删除的原错处 |

> **统一要求**：所有修改原因均须区分 `【必须修改】` 与 `【可选优化】`，保持正确原表达不变色、不强行改写。

---

## 2. 优先方案：内联彩色交互卡片（支持 Generative UI / `<agent-embed>` 的宿主）

当运行环境支持内联 HTML 组件渲染（例如具备 `generative_ui` skill 或 `<agent-embed>` 能力）时，在「修改后全文 / 完整修改版 / 修改对照」环节优先结合该能力，生成一个紧凑的内联彩色交互卡片。

### 2.1 必备交互能力

1. **视图切换**
   - **彩色修改版**（默认或一键切换）：仅以绿色、蓝色高亮展示修改与补全结果，隐藏红色删除线原错处，便于顺畅通读修改后成品。
   - **红绿删改对照**：同时显示红色删除线原错处，与紧邻的绿色替换/蓝色补全形成直观前后对照。
2. **范围筛选**
   - 提供「全文」与「第 1 句 … 第 N 句」切换胶囊/按钮；
   - 切换到任意单句时，卡片上方同步展示对应的**题干原句**（翻译题展示对应的英文原句/划线句；作文题展示对应的学生原句或写作要点提示），便于逐句精读核对。
3. **点击看原因**
   - 每个绿色、蓝色（及对照模式下的红色）高亮片段均可点击，具备清晰的悬停与当前选中态；
   - 点击任意高亮片段，在卡片底部的**固定批注栏**实时展示该处的具体修改原因，并带明确标签区分 `【必须修改】` 与 `【可选优化】`（未点击时显示简短操作提示或默认首条改动说明，避免高度跳动）。
4. **一键复制**
   - 提供「复制修改全文」按钮，点击后仅复制**干净的修改后全文**（不含红色删除线原文、不含标签与批注说明），并给出短暂的“已复制”状态反馈。

### 2.2 布局与高度约束

- **目标高度 ≤ 450px**：控制字号、内边距与行高，界面紧凑清晰。
- **避免外层卡片嵌套**：组件根容器采用轻量扁平结构，不叠加多余的外框、大圆角套壳或重阴影。
- **避免内部滚动条**：优先借助「全文 / 第 1 句 … 第 N 句」范围筛选与精炼排版控制内容高度，避免出现局部嵌套滚动条。

### 2.3 主题适配与 CSS 变量规范

必须使用宿主语义 CSS 变量配合 `color-mix()` 实现半透明高亮背景与高对比度文本，**禁止硬编码深色或浅色背景色**（如 `#ffffff`、`#000000`、`#f5f5f5`、`#1e1e1e` 等），确保深色与浅色主题下均清晰可读：

```css
/* 容器与基础排版：复用宿主语义变量 */
.diff-shell {
  color: var(--foreground);
  background: transparent;
  border: 1px solid var(--card-border);
  border-radius: 10px;
  padding: 12px 14px;
}

.diff-surface {
  background: var(--card);
  border: 1px solid var(--card-border);
}

.diff-muted {
  color: var(--muted-foreground);
}

/* 绿色：替换或修改后的正确表达 */
.hl-replace {
  background: color-mix(in srgb, var(--success) 16%, transparent);
  border-bottom: 1.5px solid color-mix(in srgb, var(--success) 65%, transparent);
  color: var(--foreground);
  border-radius: 3px;
  padding: 0 3px;
  cursor: pointer;
}

/* 蓝色：补全漏译、缺失成分或新增必要衔接 */
.hl-add {
  background: color-mix(in srgb, var(--primary) 16%, transparent);
  border-bottom: 1.5px solid color-mix(in srgb, var(--primary) 65%, transparent);
  color: var(--foreground);
  border-radius: 3px;
  padding: 0 3px;
  cursor: pointer;
}

/* 红色（带删除线）：原文中的错误表达 */
.hl-del {
  background: color-mix(in srgb, var(--error) 14%, transparent);
  color: color-mix(in srgb, var(--error) 85%, var(--foreground));
  text-decoration: line-through;
  border-radius: 3px;
  padding: 0 3px;
  cursor: pointer;
}

/* 选中态强调 */
.hl-active {
  outline: 1.5px solid var(--foreground);
  outline-offset: 1px;
}
```

- 顶栏紧凑排列：三色微型图例 + 视图切换（「彩色修改版」/「红绿删改对照」）+「复制修改全文」按钮。
- 句级筛选条：单行紧凑排列「全文」「第 1 句」…「第 N 句」。
- 底部固定批注栏：单区固定呈现当前选中片段的改动类型标签、`【必须修改】`/`【可选优化】` 标识与中文原因说明。

## 3. 降级方案：纯文本 / 无 HTML 渲染环境或写入本地 `.md` 文件

当宿主不支持内联 HTML 组件渲染，或用户明确要求将批改结果直接写入本地 `.md` 文件时，**禁止退回单纯的 `**加粗**` 标注修改**，按宿主渲染能力依次采用以下降级规则：

### 3.1 降级档 1：支持行内 HTML / KaTeX 颜色的 Markdown 渲染器

在支持行内颜色语法的 Markdown 渲染器中，使用彩色标签或行内颜色标记呈现修改句与修改对照，并在开头附一行三色图例（绿=替换/修改后正确表达，蓝=补全漏译/缺失成分/衔接，红删除线=原文错处）：

- 行内 HTML 彩色标签示例：
  - 绿色替换：`<span style="color:#16a34a">替换后的正确表达</span>`
  - 蓝色补全：`<span style="color:#2563eb">补全的成分或衔接</span>`
  - 红色删除线：`<del style="color:#dc2626">原文错处</del>`
- KaTeX 颜色标记示例（仅当目标渲染器屏蔽 HTML 但支持 KaTeX 颜色时选用）：
  - 分别使用 `\textcolor{green}{...}`、`\textcolor{blue}{...}`、`\textcolor{red}{\text{...}}` 标注对应改动。

### 3.2 降级档 2：严格纯 Markdown 环境（无 HTML/颜色渲染或纯文本 `.md`）

在无法渲染颜色的严格纯 Markdown 环境中，禁止使用 `**...**` 代替修改标注，采用 `diff` 代码块逐句对照 + 行内语义改动清单，并在完整修改版处提供干净可直接复制的修改后全文：

````markdown
```diff
- 原句：...
+ 修改句：...
```

- `[删改/红 → 替换/绿]` 【必须修改】`原错处` → `正确表达`：具体修改原因。
- `[补全/蓝]` 【必须修改】补全 `缺失成分/漏译内容`：具体修改原因。
- `[替换/绿]` 【可选优化】`原表达` → `更自然表达`：优化说明。
````

- **逐句批改**：每句以 `diff` 代码块对照原句与修改句，紧跟行内改动清单说明原因。
- **修改后全文 / 完整修改版**：先提供逐句或分段的 `diff` 删改对照与改动要点，再附上一段无任何删除线与多余标记的**干净修改后全文**，方便直接复制使用。
