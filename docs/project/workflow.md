# 仓库维护流程

本页是 [AGENTS](../../AGENTS.md) 的维护细则。安装后的 Skill 只使用自身资源。

## 检查点与恢复

- 开工按 AGENTS 核对规则、范围与完成条件。复杂任务给简短计划。实质修改前刷新 [检查点](progress.md)，记录目标、授权及禁止动作、最近完成步骤与证据、当前步骤、本次修改及未提交状态、精确下一步、阻断或待决事项、外部动作与恢复指令。区分用户原有改动。
- 一组相关修改、一次完整审计或一类验证算一步。每步核验后更新进度相关栏目并复读，再进入下一步。长测试启动前和有结果后各记录一次。
- 可预见的上下文压缩前暂停新工作，落盘中断位置、产物、结果与下一步，核对 Git，必要时更新 [胶囊](../spec/99-context-capsule.md)，复读两页。瞬时状态只写检查点，持久背景写胶囊。写入失败先处理并核实。
- 无预警压缩后按 AGENTS 恢复，核对检查点、Git diff 和产物，补齐事实，复用已完成工作。平台压缩后做恢复审计。
- 产品变更同步 SPEC、受影响分层和矩阵；纠错同步 lessons；持久阶段变化同步胶囊。交付前查 diff 和工作区，报告改动、当次证据、剩余问题及安装、提交、推送、发布状态。

## 按影响验证

验收数量、阻断项和顺序以 [测试规范](../spec/07-testing-acceptance.md) 为准。

| 改动 | 验证 |
|---|---|
| 治理、链接、进度、拼写 | diff、引用、规范一致性 |
| 纯输出排版 | 结构及输出类合成用例 |
| Skill 指令删重、路由、流程 | 结构、规范映射、全部 24 个公开合成用例 |
| 数学方法、条件、范围或阻断修复 | 失败用例 → 同类 → 全部固定回归（至少 36 道）→ 必要时新未见题 |
| 完整重新验收 | 至少 24 个合成、36 道固定、12 道未见题 |

- 结构检查覆盖 frontmatter、目录名、相对链接、一层引用、可移植性、YAML、资源边界与 `git diff --check`。运行 skill-creator 快速校验器，缺依赖时记录失败并用现有工具等价检查；`skills-ref` 可用时运行。
- 行为验证执行实际请求并保留输出和观察断言。静态检查、预测与历史报告各按自身证据类型记录。前向验证可由环境允许的独立子 Agent 执行，仅给请求、Skill 与必要上下文，答案和修复结论留给复核者。输出放隔离临时目录，回传可公开短结果与验证摘要，维护者审查后及时归档。原创用例可存完整输出；真题原文留在临时目录，仓库只存定位、短结果和核验摘要。
- 必要检查通过即结束。仅因新改动、失败或未解决风险扩大范围。报告保留日期和执行者；已解封题退出新盲测和指令调优。

## 纠错

指出错误，搜索并修正直接错误及派生引用，按“现象 → 原因 → 防止规则”更新 [lessons](lessons.md)，再验证。长期规则保留一个执行落点，其余文档引用。
