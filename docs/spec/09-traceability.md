## 2. 已明确不做或受控执行

| 项目 | 状态 | 理由 |
|---|---|---|
| 自动安装 Skill | 禁止 | 用户要求只保存仓库 |
| GitHub 推送与发布 | `v1.0.1` 已发布 | 用户批准删除“验证”板块后的正文；提交、push、tag 与 Release 已核验 |
| API Key 或直接调用云端模型 | 禁止 | Agent-only |
| 真题 PDF 进 Git | 禁止 | 体积与版权 |
| 估分与得分点 | 禁止 | 无权威细则，易产生无依据结论 |
| 学习规划与错题管理 | 超出范围 | Skill 只服务解题、理解与纠错 |
| Skill 内 README | 禁止 | 根 README 统一维护 |
| 客户端专用安装目录 | 不提供 | 使用通用 Agent Skills 路径 |

## 4. 冲突审计结论

当前规范已解决的主要冲突：

- “只提供解题”已细化为“具体题目解答、用户错解纠正、定理原理推导”，仍排除备考管理。
- “数学一全部内容”已澄清为覆盖数一、数二、数三的全部考研数学范围。
- “代码永远比推理可信”已校准为：检查输入、假设、实现和精度后，工具在复杂计算上优先；冲突时同时审查。
- “条件不足”已区分为输入残缺与题目故意考查不能推出。
- “跨 Agent 兼容”已限定为开放格式兼容，不承诺未测试客户端行为一致。

当前没有已知未裁决的产品需求冲突。
