## 执行方法与证据

- 首轮：两个独立子 Agent 各执行 12 个公开请求，主 Agent 审查。输入只含 ID、prompt、context，未给预期答案或旧报告。原始回答及 Skill 快照见 [首轮证据](astra-forward-initial.json)。
- 修复后：另一独立子 Agent 执行全部 24 例和 3 个补充边界/来源请求；另一个子 Agent 运行 2 个同题/仅答案请求。后两项在服务范围修复前运行，路径未改变。实际回答与当前 Skill SHA256 见 [最终证据](astra-forward-final.json)。
- 这是批次内逐题生成、维护者人工断言审查，不是每例单独新建真实用户会话，也不是多次随机盲测或 A/B 性能实验。截图用例为原有文字描述，未冒充真实图像识别测试。
- 本轮独立执行者未读取数学未见题。固定回归另行直接只读原卷，先推导落盘再查答案册。
